## Frozen MTO-36 experiment and automatic gates

- Inputs: SHA-pinned `training_features.tif`, `labels.tif`, `sample_submission.tif` (owner's mirrors in `registry/data_manifest.json`); no SGMC, QFault-trace attribute, scored TIFF, or other label-derived feature in any model. The existing `scripts/prepare_data.py` / cached band stack and shared `gems.holdout.SegmentHoldout`, `gems.submission.write_submission` + `check_variants`, and `gems.novelty.compare_registry` are authoritative. If a shared tool is wrong, fix the template and tests, not a private fork.
- Physics: Gaussian `rtp` gradient at σ=2 px; local tangent estimated from the same field. Sample edge strength ±6 px along the tangent using bilinear interpolation. `termination = edge_strength × (1 − min(arms)/(max(arms) + ε))` where a one-sided strong/weak arm signals a contact endpoint, not a continuous edge. Smooth gravity gradient at σ=3 px; `crosscut = termination × scaled_gravity_strength × |sin(θ_m − θ_g)|`. A second feature is `termination` without gravity, so the canary can isolate the crossing term. Clamp physical strengths robustly on *unlabelled footprint* pixels; drop unsupported inputs. This is a geometric hypothesis, not an inferred detection probability.
- **E1 only (unless justified and documented before proceeding):** label-free candidate `0.75 × crosscut + 0.25 × termination` versus matched `rtp` edge-strength control (identical fold, budget and emission). No hyperparameter tuning after seeing the test-fold score. The corridor where topographic scarp evidence is absent is a secondary *descriptive* slice, not an optimized gate. If E1 cannot beat the comparable group best, the verdict is **negative**; do not spend a slot. Maximum three experiments / two hours total.
- Shared holdout: four spatial quadrants; whole 8-connected fault components hidden across each test fold with a 15-px / 1.5-km buffer; recompute any catalogue-derived quantities only from `fold.visible` (none in E1); mask `fold.visible` pixels exactly in both score and emission. Pooled TPw/FPw/FNw, α=0.2 β=0.8, triangular Euclidean R=3 px (300 m); shared template 10-km-block-bootstrap 95% CI, 1,999 draws. Count withheld positives and components. Canary every feature used alone in either polarity on the shared holdout; >0.90 AUC is presumptive leakage and stops promotion.
- Dot emission: 37,654 binary pixels maximum split by quadrant footprint area, shared `h36_emission.emit_dots` (ridge NMS then >=3-px spacing), scored only in the validation quadrant. Full-map inference uses this *same label-free field*, with pixel-exact catalogue exclusion and >2 px collar (borrowed only as a well-understood control, not a copied mask). Explicitly compare to prior rasters **before** placing dots (surface rank) and **after** placement (3-px directed overlap; max thresholds 0.90/0.70 **literal**). If either fails, log duplicate, stop: no novelty waiver for dense blankets, no post-hoc dot relocation.
- Promotion requires: leakage and both novelty checks pass for a complete fetched registry; matched baseline beaten with strictly positive paired 95% CI and 3/4 fold wins; shared evaluator DTI exceeds the *recorded* comparable 0.14876 holdout (recorded in GEMSDOE24, not re-run here); and sample-grid + whole-array finite [0,1] checks pass. Even promotion would **not** itself spend a live submission slot; a separate selector within the portal's current limit is needed.
