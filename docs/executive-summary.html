Brief

What the challenge asks.

Predict geological faults across the GeoDAWN region as a one-band confidence raster. The target is newly identified, potentially off-catalogue fault geometry—not heat-flow favorability by itself.

Scoring

Distance-weighted Tversky

The official problem page specifies α = 0.2, β = 0.8, and a triangular kernel with 300 m support. Per-truth-pixel maximum credit means nearby redundant predictions can add false-positive mass without adding true-positive credit.

Selected research lead

Stress-constrained lineaments

Combine multiscale geophysical structure with a locally uncertain stress-orientation penalty inside the differentiable training objective. The implementation is unit-tested on synthetic arrays only; no real-data benefit is measured.

Submission steps

The safe path from data to upload.

Follow in order. The model and file download are withheld until the validation result is real.

  1. Enroll and obtain official files

    Use the official data page after accepting the rules. Place files locally under data/raw/. Do not paste credentials into the repository or share them with an assistant.

  2. Audit geometry and NoData

    Run python scripts/audit_inputs.py --features data/raw/training_features.tif --labels data/raw/labels.tif --template data/raw/sample_submission.tif. Confirm the authorized template is the source of the output mask—not feature-band nodata.

  3. Run the reference and spatial holdout

    Read the preregistered validation plan. Compare H1 to the organizer reference using contiguous spatial folds, train collars, exact DTI, fixed emission budget, and stress ablations. Do not use random pixel splits as the main result.

  4. Build from your own score array

    Save the chosen full-grid score field as a 2-D NumPy .npy array. Then run python scripts/build_submission.py outputs/prediction.npy --template data/raw/sample_submission.tif --note docs/submission_note.txt. The writer creates a UTC/hash-unique name and JSON manifest.

  5. Validate the exact bytes

    Run python scripts/validate_submission.py outputs/submissions/FILE.tif --template data/raw/sample_submission.tif --json. Inspect the report and manifest. Any nonfinite in-bounds value or value outside [0,1] is a hard failure; a local PASS still does not guarantee portal acceptance.

  6. Write the required AI narrative and upload manually

    Adapt the AI disclosure draft to the actual work. Read the current official rules, use the manual DrivenData upload form, preserve the response/score receipt, and observe the three-per-week limit and single final-selection rule.
