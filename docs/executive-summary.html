Submission guide

When a future file can be considered

  1. Resolve the registry/budget blocker with a scientifically justified plan, not threshold changes or lattice-hole targeting. Refresh all nine pinned inventories and the full registry. A non-failing feasibility bound is not a uniqueness pass.
  2. Use one preregistered lane and the shared feature stack, evaluator and writer. Screen the surface against every registry raster before placement and final dots afterward; stop on |rank correlation| >0.90 or >70% within 3 px of any entry.
  3. For holdout, hide whole fault segments with buffer, derive catalogue features from visible faults only, mask visible pixels exactly, test each feature for AUC leakage and pool DTI using α=0.2, β=0.8 and a 300 m triangular kernel. Record evaluator, positives and 95% CI.
  4. Validate the real file automatically: a single-band GeoTIFF (.tif), float32, correct CRS, shape, and geotransform, all predicted values finite and within [0,1] as applicable, plus official null/NaN outside-footprint requirements. A .zip file containing a single GeoTIFF is also allowed. Resolve the full-array-vs-outside-NaN ambiguity from the authorized sample/organizer guidance; do not claim portal acceptance from a local check. A prior portal message was “Predicted values must be in range [0, 1]”. See the official format and metric.
  5. Record the SHA-256, validator output, run card and ≤140-character note. Only a separate selector can choose a live upload; official rules allow three weekly slots and one submission for both prize rounds. None is selected now. The official competition page listed 3 December 2026, 23:59 UTC as the deadline when checked on 26 October; recheck the competition page, rules and AI disclosure.
