   - `B0`: `59` `BASE_FEATURES` (`emit_dots` top-$K$ control).
   - `EXP-1` (`CSDL-Structural-75`): `59` `BASE_FEATURES` + `16` `CSDL_STRUCTURAL_FEATURES` = `75` features (**zero** hydrothermal conduit features), isolating `CSDL-36-A`.

   - `EXP-3` (`CSDL-TwoRegime-Bridge-87`): `87` `EXP-2` features (`M_full`) + `73` LiDAR-blind features (`M_blind`) + 3-tier relief-conditioned LiDAR-gap calibration + Two-Regime 300 m CELF submodular allocation (`72%` primary ridge + `28%` concealed subsurface/conduit), isolating `CSDL-36-C`.
2. **`IR-GVSC36-02` (Removal of Invalid `det_elev <= -60 m` Lake Lahontan Proxy):**
   - `12_det_elev` is local detrended relief, not absolute elevation above sea level. `rasterize_deconfounded_geothermal_layers` in `src/gemsdoe36/csdl_features.py` classifies `Paleo_geothermal_final.csv` purely by mineralogical/structural deposit type (`IN_SITU_VENT_TYPES` vs `OUTFLOW_APRON_TYPES`, with `Tufa = 0.65` and `Travertine = 1.0` globally) and never thresholds `det_elev`.

   - In `scripts/run_csdl36.py`, `compare_registry(prob_surface, dots=None, ...)` is executed and UTC-timestamped (`pre_placement_surface_check_utc`) **strictly before** calling the submodular dot emitter (`dot_emission_started_utc`), and verified by `scripts/verify_csdl36_release.py`.
4. **`IR-GVSC36-04` (Exact Programmatic Feature Counts):**
   - Asserted at import time in `src/gemsdoe36/csdl_features.py` and against this preregistration: `BASE_FEATURES = 59`, `CSDL_STRUCTURAL_FEATURES = 16`, `CSDL_CONDUIT_FEATURES = 12`, `EXP1_FEATURES = 75`, `EXP2_FEATURES = 87`, `LIDAR_FEATURE_SET = 14`, `EXP3_BLIND_FEATURES = 73`.
