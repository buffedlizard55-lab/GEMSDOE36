## Registry gate and decision

The local `reg-052` reference is a dense regular lattice. Its 3-pixel neighborhood covers **5,160,724 / 5,167,373** footprint pixels (99.8713%). For a 37,654-dot candidate, a pigeonhole bound forces at least **31,005 dots (82.3418%)** within 3 pixels. The threshold is forced above 70% from **22,164 dots** upward.

This proves that the literal test is non-discriminating for ordinary candidate densities against this reference. It does **not** prove an unseen, scientifically different detector is a duplicate. No threshold was changed and no candidate was generated to bypass the gate. The surface-rank-correlation and final-dot checks were not run for a new candidate because none exists. The comparison rasters are SHA-pinned owner/GitHub copies, not organizer-authenticated registry data.
