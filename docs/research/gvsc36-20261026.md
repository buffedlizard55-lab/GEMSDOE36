The surface was not tuned after the check, but required chronology “surface gate before placement” was violated. Future code has been reordered; this completed run remains flagged and negative.

- **Historical score provenance:** nine-site values remain **OWNER-REPORTED**, not ORGANIZER-CONFIRMED; no portal receipt pairing uploaded bytes and score is archived.
