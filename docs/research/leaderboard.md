# Leaderboard review policy

The [official public leaderboard](https://www.drivendata.org/competitions/306/competition-doe-gems/leaderboard/) is the authoritative place to see current public scores. It changes over time; a public score is not the private test score, final prize score, or evidence tying an account to a file in this repository.

The page was checked once on **2026-10-04 UTC** in response to the request to investigate a reported **0.2778**. That value is not verified as a score earned by GEMSDOE36/GEMSDOE32 or as the score of any local TIFF. No upload receipt or file-to-account evidence is present in this workspace.

**No score table or participant-name snapshot is mirrored here.** DrivenData's [Terms of Use](https://www.drivendata.org/termsofuse/) prohibit automated access for monitoring/copying and also manual monitoring/copying without prior written consent. That conflicts with the requested public dated snapshot, so the site records only the observation date and directs readers to the official live page. Do not publish or refresh a copied leaderboard snapshot without written permission or a confirmed authorized API. No scraper, poller, or feed is shipped.
