## External-data rules and scientific guardrails

- The official problem page allows additional sources if the competitor has a license permitting use in the challenge **and sharing with the sponsor for evaluation**. Record the exact release/version, license, citation, and processing lineage before using external data.
- A free public catalog only verifies that an access route is listed. It does not prove local acquisition, relevant AOI coverage/resolution, license compatibility, or incremental DTI value.
- WSM SHmax orientation is not a universal fault-trace orientation. For normal-faulting regimes, a plan-view extension axis is a plausible trace-normal prior; mixed/strike-slip/thrust domains need regime-specific distributions or zero prior confidence.
- Geodetic strain and crustal stress are related but not interchangeable; do not label a strain-derived axis as a direct stress observation.
- Geophysical contacts, DEM scarps, drainage bends, radar lineaments, geothermal favorability and seismic swarms can all be non-fault signals. Validate with spatial blocks, controls, and geological review.
- No external data source listed here has yet passed the AOI coverage and usefulness gate; no external file was acquired in this review.
