Method, not leaderboard theater

A score is not a scientific claim.

GEMS scores continuous fault-confidence rasters with a 300 m distance-weighted Tversky index. Good work must find off-catalogue structure without mistaking every geophysical edge for a fault.

Objective

Discover new traces

Predict faults that are absent from the current public catalogue. A geothermal favorability layer is context—not ground truth.

Physics-informed

Stress belongs in the loss

A differentiable axial-orientation penalty is implemented with uncertainty weighting. It is not a compass filter applied after inference.

Validation

Block space, not pixels

Spatial folds and collars are specified before modeling. A 5-fold spatially-blocked holdout (512 px blocks, 30 px collar, seed 36) has run; the lead candidate passed 5/5 folds before this submission slot was used.

Trust & reproducibility

What exists—and what does not.

The project started from a README-only repository. It now contains the competition data (SHA-pinned mirrors), a full feature→belief→emission pipeline, a passed 5-fold spatial holdout, and a gate-validated upload-ready TIFF. It does not yet contain an organizer score.

Implemented and testable

Published DTI calculator; differentiable stress-orientation loss; spatial block-fold utility; multi-family belief field with off-catalogue SGMC prior; exact-marginal-gain emitter; strict template-based writer and validator; physics-informed U-Net (training configured); synthetic + real-data tests.

Read the holdout and release gates →

Still open

Organizer acceptance and a live leaderboard score for the candidate TIFF; the CNN ensemble (H5) has not yet beaten the H6 holdout best, so it is not in this file; the proxy→live transfer is only partially calibrated (the SGMC proxy over-counts old faults).
