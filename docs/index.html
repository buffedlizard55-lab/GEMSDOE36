How to submit

Making a competition submission

  1. Download the official sample_submission.tif template from the data tab (DrivenData login required).
  2. Produce a 3730×3292 single-band float32 array in [0,1]; sanitize NaN/Inf so no value falls outside [0,1].
  3. Write using the template's profile (EPSG:32611, shape, geotransform), nodata=None, 0 outside the footprint (zeros variant).
  4. Validate with python scripts/validate_submission.py yourfile.tif --template sample_submission.tif.
  5. Upload the .tif or .zip on the submission page with a unique name and ≤140-character note.
